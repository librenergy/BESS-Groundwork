# Metrics Tree (MT)

* [Metrics Tree & KPIs](metrics-tree.md) - One document: the tree (how contract value decomposes through LDs and guarantees, into the OBE engineering measurement layer, down to data sources), the authoritative metric definitions, and the KPI target set (a KPI is a metric held against a target).

## Status

* **Template, v0.2 (2026-08-25).** Rebuilt from a generic merchant shape into a **performance-engineering shape**: four limbs (contract revenue and its LD deductions, vendor LD recovery, operating costs kept shallow, guarantee preservation as the gate) over a shared **OBE measurement layer** (EA / OA / PA / QA) that both contractual availability streams resolve into. Drafted in a cloud Mermaid editor as the working copy; the block in the document is a synced snapshot. Populated through the `metrics-tree` skill; depends on the EIM, the [Data Interface Register](../Data_Interface_Register%28DIR%29/data-interface-register.md), and the [Performance Guarantee Matrix](../Performance_Guarantee_Matrix%28PGM%29/performance-guarantee-matrix.md).
