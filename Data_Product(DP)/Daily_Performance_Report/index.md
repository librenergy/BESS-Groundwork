# Daily Performance Report

Daily BESS performance report: availability under each contractual definition (equipment, power, operational, combined), energy and efficiency, data quality, commercial events, and the parameter block that makes the numbers reproducible.

* [daily-performance-report.md](daily-performance-report.md) - The specification and Markdown template: section-by-section structure, what each availability definition measures, how to present the excused / depth-weighted axes, and the conventions to pin down before the first issue.
* [daily-performance-report-template.html](daily-performance-report-template.html) - Render skeleton for the generator: 700px inline-styled table layout, KPI tile pattern, table styling, base64 chart embedding, palette. Survives email clients and headless-Chromium PDF export.
