# Log

## 2026-08-21

* **v0.2 — renamed `Telemetry_Mapping` → `Grid_Telemetry_Mapping` and rebuilt from the first project clone's matured draft** (`telemetry-map.md` → `grid-telemetry-map.md`; the v0.1 general-telemetry skeleton replaced wholesale). The product is now explicitly the **grid interface only**: one table from the BESS SCADA point of view, Out rows GT-01…19 (heartbeat, meter quantities, setpoint echo, energy/SOC set, dispatchable powers, aux load, statuses, derate and meter-health alarms) and In rows GT-51/52 (dispatch setpoint, ramp-rate setpoint). Columns use `source.tag` notation: **Source** (originating system.tag), **Monitoring Tag** (the performance engineer's read path, `historian.GRID_*` proposed convention; not the RTAC, which only operations reach), **Grid RTAC tag address** (`dnp3.*`; `reserved` marks rows the operator hasn't taken). Clone-session lessons baked into the row notes: single measurement basis at the point of delivery; operating-SOC-limit points redundant with self-adjusting Full Battery Energy; expect the operator to ask for SOC in MW and %; the dispatch-setpoint mechanism decided early; energy points availability-reflective. Ported from the first project clone, where the map was built against the integrator's points list and ERCOT/CAISO reference lists.

## 2026-08-20

* **v0.1 — template created.** New data product: the master IO list, the tag-level companion to the Data Interface Register — where the DIR catalogues systems (SYS-NN) and flows (IF-NN), this map holds one row per canonical signal with its source of truth and its tag name/address in each observing system (EMS, SCADA, historian, grid chain). Structure: §1 per-system tag addressing and where each authoritative tag list lives; §2 site-level master map (TAG-01…12: dispatchable powers, energies, aux load, available units, availability/watchdog flags, mode, setpoint, protection operations); §3 per-unit set (TAG-21…26); §4 meter & substation (TAG-31…35, with the owner-meter-tap gap flagged); §5 derived owner-side tags (formulas stay in the Metrics Tree). `TAG-NN` prefix registered in taxonomy §3. Ported from the first project clone, where the map was seeded from the OEM spec telemetry tables and the DIR.
